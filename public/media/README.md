# Hero media slot

Add approved hero assets here and update `src/lib/media.ts`:

- `hero-weiss-lake.jpg` — current supplied atmospheric still
- `hero-technician.webm` or `hero-technician.mp4`
- `hero-technician-poster.webp`
- optional `hero-technician.gif` fallback

The media component falls back to a neutral CSS treatment when neither video nor image is configured.
